# Time Shark

A clean, beautiful time tracking SPA with the following main features:  

- Time Tracker (Shark)
  - Todo / Tasks Manager
  - Time Entries Manager
- Projects Timeline
- Archive
  - Archived Projects
  - Archived Todos / Tasks
  - Archived Time Entries
- Reports
- Team
- Clients
- Organizations
- Projects

## General Requirements

- All entities should have an ID for compact reference and storage.  
- All entities should have a status field.
- All entries should support tags.
- All timestamps should be stored in unix format to save space and for easier calculations.
